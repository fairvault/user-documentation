This page offers a simplified perspective on how to request access to datasets with a given sensitivity level containing certain types of restricted data.

# Blue (Open) <img width="30" height="30" alt="lock_blue" src="https://github.com/user-attachments/assets/5cb5aa11-c2e4-45d1-b230-674ceda7f419" />

Datasets with a blue sensitivity level are shared freely, under an open license. No access request or any procedure is necessary besides adhering to the terms of the license.

# Green (Registered) <img width="30" height="30" alt="lock_green" src="https://github.com/user-attachments/assets/436e2f35-cd55-4f69-98ce-8d800570866c" />

Datasets with a green sensitivity level are automatically accessible to logged-in users. In order to access them; log in to your account via your institutional login or via ORCID, at which point you will have access under the conditions specified in the license. We ask for more information when the files are downloaded.

1. Fill out the guest book for the dataset when downloading files.

# Orange (Restricted) <img width="30" height="30" alt="lock_orange" src="https://github.com/user-attachments/assets/2ab4af5e-83f4-4259-aa8f-9089eea773d7" />

Datasets with an orange sensitivity level contain some sensitive or confidential data, and as such, are only available after a Data Access Request. Do the following:

1. Request access to one or more restricted files in the dataset.
2. Fill out the guest book for the dataset when requesting access.
3. The access request is handled by curators and the original data owner.

# Red (Metadata only) <img width="30" height="30" alt="lock_red" src="https://github.com/user-attachments/assets/c4f9fef6-d1e2-402f-8354-5ff1f7052139" />

Datasets with a red sensitivity level are considered to contain highly sensitive or highly confidential data. Access can only be granted in exceptional cases. These often come with specific access conditions, and always with a Data Transfer Agreement.

1. Contact FAIRVault support about this dataset to request access. They will walk you through the process of getting access to this specific dataset.
